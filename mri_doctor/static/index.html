Inference runs on your computer. Original uploads are removed after processing. Results stay in server memory for up to one hour, or until you delete them.

Start with the right input.

Spinal cord segmentation uses T2 NIfTI. Knee studies use DICOM series. Brain analysis requires preprocessed NIfTI volumes with N4 correction, template registration, and skull stripping.

Context comes first.

Probabilities belong to specific research tasks. IDH estimates mutation status in glioma; it does not detect tumor presence. Review model results with a radiologist.
